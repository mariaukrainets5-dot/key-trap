# Ловушка ключей — мод для Claude Code

Вставили в сообщение API-ключ или токен бота? Мод перехватывает его до отправки. Ключ сохраняется в `.env` проекта, а в чат уходит только имя переменной: `[ключ OPENROUTER_API_KEY сохранён в .env, значение скрыто]`. Значение не попадает ни в переписку, ни в файлы сессии на диске.

## Как это работает

Если в сообщении есть ключ, мод спрашивает:

- **Сохранить в .env** — ключ записывается в `.env` в папке сессии, сообщение уходит без значения. Если в `.env` уже есть ключ с этим именем, он заменяется новым, остальные строки остаются. Если папка — git-репозиторий, а `.env` не указан в `.gitignore`, мод его туда допишет.
- **Other** — впишите другую папку проекта (например, `~/projects/my-bot`), ключ ляжет в её `.env`.
- **Отправить как есть** — сообщение уходит без изменений.
- **Не отправлять** — сообщение не уходит, текст возвращается в поле ввода.

Узнаёт ключи OpenRouter, OpenAI, Anthropic, ElevenLabs, токены Telegram-ботов, Brevo, Supabase `service_role`, Stripe, GitHub, Groq, Airtable, Google, AWS, Slack, Railway и Vercel. Если ключ написан как `ИМЯ=значение`, имя берётся из текста. Публичный anon-ключ Supabase не трогается. Приватный ключ (`BEGIN PRIVATE KEY`) в чат не пропускается.

Мод ничего не отправляет в интернет: он только читает ваше сообщение и пишет в `.env` и `.gitignore` на вашем компьютере.

## Установка

В терминале, в сессии Claude Code:

```
/plugin install key-trap --marketplace mariaukrainets5-dot/key-trap
```

Ответьте `y` на вопрос о маркетплейсе, затем выберите область установки (user — для всех проектов).

Из обычного терминала:

```bash
claude plugin install key-trap --marketplace mariaukrainets5-dot/key-trap
```

В приложении Claude (вкладка Code), где `/plugin` не работает: нажмите + рядом с полем ввода → Plugins → Add marketplace → `mariaukrainets5-dot/key-trap` → Add plugin.

Нужен Claude Code 2.1.286 или новее.

## Выключить

`/plugin` → Installed → key-trap → Disable.
